## 三、结构诊断：赢家分散，输家集中

### 核心矛盾
组合最大的问题不是"选错方向"，而是**仓位配置与判断相互矛盾**：

1. **XPEV 是全组合最大单票（4 份 / 12.8%），却是持续下跌的失血标的**，与"早就计划退出新能源车"的判断严重冲突——又一次"温水煮青蛙"。
2. **加密敞口高达 19.2%（BTC 3 + CRCL 3）**，而 BTC 已跌破熊市生命线（半年 -50%）、CRCL 逻辑崩塌（护城河被 OpenAI USD 冲击），双重承压。
3. **真正的赢家（NBIS、MU、AMD、AMAT、COHR）反而仓位偏小或分散**，MU/COHR 各只有 0.5~0.7 份，没能充分放大主线收益。

一句话：**该重的（存储/算力赢家）不够重，该砍的（新能源车/加密）反而最重。**

## 四、分标的调整建议

### 🔴 减仓 / 清仓（释放约 8~10 份弹药）
- **XPEV（4 份）**：坚决减仓至清仓，反弹即走。最大单票 + 失血源 + 与既定判断矛盾，没有理由继续重仓。
- **CRCL（3 份）**：止损离场。稳定币护城河被侵蚀，逻辑未修复前不补仓。
- **BTC（3 份）**：减至底仓（保留 0.5~1 份观察）。熊市未确认反转前控制敞口。
- **QUBT / XE（1.2 份）**：清理。题材股趋势向下，占比小且消耗注意力，腾挪给主线。

### 🟡 观察 / 控制
- **NOK（1.6 份）**：仓位偏重，走弱可减。AI 网络受益逻辑存在但估值偏高（PE 77）。

- **泡泡玛特（0.5 份）**：持有观察，非核心，仓位小可保留。

### 🟢 持有 / 加仓（回补主力）
- **存储三件套（海力士 2 + DRAM 3 + MU 0.5）**：**优先回补方向**。HBM 超级周期最强主线，MU 仓位过小应加大。
- **NBIS（3.7 份）**：核心持有，回调加仓，半年最大赢家。
- **AMD / TSM / AMAT / MRVL / COHR**：持有，AMAT/COHR 走势最强可小幅加。
- **GOOG（1 份）**：持有可加，稳健底仓，估值合理。

## 五、调仓总方向

> **把"赢家分散、输家集中"扭转为"赢家集中、输家出清"。**

- **砍**：XPEV / CRCL / BTC(部分) / QUBT / XE，合计释放约 8~10 份。
- **加**：集中回补到 **存储(MU/海力士/DRAM) + AI算力(NBIS/AMD/AMAT)** 主线。
- **留弹药**：现金比例可从 3% 提升到 5~8%，用于主线回调时的低吸，克服"怕追高"的心结——趋势明确时，有纪律的追高不是错。

这也是下半年把整体收益从 +22.7% 拉回 +50% 目标的唯一可行路径：**用赢家的确定性，覆盖并替换掉输家的失血。**
