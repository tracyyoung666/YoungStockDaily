# Markdown → 微信纯文本转换规则

微信客户端（企业微信/个人微信）不支持 Markdown 和富文本渲染，直接粘贴 `**粗体**`、`|表格|` 会显示字面字符。因此 Web3 日报推送必须转为纯文本。

## 转换规则（严格按顺序执行）

1. **删除所有 Markdown 标记字符**
   - `**加粗**` → 去掉星号
   - `# 一级标题` → 改为 emoji + 文字，如 `📊 市场概览`
   - `## 二级` → emoji + 文字
   - `> 引用` → 改为缩进或 emoji 前缀 `💬`
   - `` `行内代码` `` → 去掉反引号
   - ```` ``` 代码块 ```` → 原样保留但去掉围栏
   - `[text](url)` → 保留为 `text（url）`
   - `---` 水平线 → `━━━━━━━━━━━`

2. **表格改写为竖排列表**
   - 禁用 `|` 竖线
   - 多列用全角竖线 `｜` 或换行
   - 示例：
     ```
     ・Bitcoin BTC｜$112,500｜+2.3%
     ・Ethereum ETH｜$4,120｜+1.8%
     ```

3. **关键数字加千分位**
   - `4890万` → `4,890 万美元`
   - `1.6亿` → `1.6 亿美元`
   - 百分比保留一位小数：`+2.3%`

4. **emoji 分段标题**（与日报内容匹配）
   - 📊 市场概览
   - 🌐 宏观分析
   - 💸 资金流向
   - 🗣️ KOL 舆情
   - ⚠️ 风险警示
   - 💡 机会信号
   - 🎯 一句话总结

5. **分隔线**（视觉分段）
   - 主分隔：`━━━━━━━━━━━━━━━━━━━━━`
   - 次分隔：`— — — — — — — — — —`

6. **段落间留空行**，避免一堵墙文字

7. **保留全部信息**
   - 市场概览、宏观主题、资金流向、KOL 舆情、风险警示、机会信号、一句话总结、数据统计、免责声明 — 一条不能删

## 示例对照

### 原始 Markdown
```markdown
# 📅 Web3 日报 | 2026-04-28

## 📊 市场概览

| 资产 | 价格 | 24h 涨跌 |
|---|---|---|
| BTC | $112,500 | **+2.3%** |
| ETH | $4,120 | +1.8% |

> 恐贪指数 72（贪婪）
```

### 转换后微信版
```
📅 Web3 日报 | 2026-04-28

━━━━━━━━━━━━━━━━━━━━━
📊 市场概览
━━━━━━━━━━━━━━━━━━━━━

・Bitcoin BTC｜$112,500｜+2.3%
・Ethereum ETH｜$4,120｜+1.8%

💬 恐贪指数 72（贪婪）
```

## 实施提示

- 可以用 python 一次性替换：按正则逐条剔除 Markdown 符号，再按段落重建。
- 如果内容里原本有表情（📊 📈 🪙 等），直接保留，它们就是分段视觉锚点。
- 长表格建议按「每行一条」转为竖排列表；若有多列且无法合并，用 `｜` 分列。
